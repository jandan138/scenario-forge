05 / 本轮刻意不做

  • 玻璃棒：本轮不改。
  • 瓶塞：不属于透明玻璃主体范围。
  • 平底烧瓶磨口：保留磨砂，不整件覆盖。
  • 任务结果：不继承机器人策略、液体转移或 benchmark 成功结论。
