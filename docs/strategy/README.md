# Strategy Documents

Strategy documents describe product direction and sequencing. They are forward-looking
and are not evidence that the described capabilities are implemented.

Durable contracts belong in `docs/design/`. When a strategy document and a design
document differ, the design document is the source to use for implementation until
the strategy document is revised.
