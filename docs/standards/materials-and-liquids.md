# 材质与液体规范

状态：当前。已验证案例主要是 Isaac Sim 4.5 的滴定 r1.6、斐林水浴 r2，以及各自记录中限定版本的液体原型/接入。
视觉假液体、物理液体和沉淀的规则分开适用。

## 强制要求

<a id="mat-001"></a>
### MAT-001 — 区分视觉表现与物理能力

声明每一部分是视觉假液体、PBD 等真实运行的液体表示，还是视觉沉淀。
假液体可以用于明确受限的交互展示，但不能因此宣称会保持水平、晃动、流出、产生化学反应或完成液体转移。
需要物理液体能力时走 [资产接入](asset-intake.md) 和对应流体契约，不在纯包层加入 SDK 或消费者碰撞修复。

依据：[原型范围](../records/2026-08-16-visual-static-liquid-prototype.md)、
[滴定 r1.6](../records/2026-09-07-titration-r16-single-material.md)、
[水浴 r2](../records/2026-09-08-fehlings-water-bath-r2-sedimentation.md)。

<a id="mat-002"></a>
### MAT-002 — 按实际 Shader 读取和更新

确认几何绑定到哪个 Material/Shader，再使用真实存在的属性，验证类型、数值和实际显示。
不要仅凭节点名或函数返回值推断渲染已经更新；离线读取文件与运行中的 Stage 也必须区分。

| 已验证路线 | 颜色属性 | 透明度注意事项 |
|---|---|---|
| 滴定的 OmniGlass | `inputs:glass_color`，`color3f` | 该案例没有 `inputs:opacity`；返回的兼容 opacity 未写入实际 Shader |
| 水浴的 UsdPreviewSurface | `inputs:diffuseColor`，`color3f` | `inputs:opacity` 确实存在并更新 |

RGB 输入不是截图像素，也不单独决定透明度。反射、折射、灯光和背景必须进入目视判断。
业务读取优先通过关系解析目标；需要重命名时遵守 [USD-002](usd-layout.md#usd-002)。
依据：[滴定教学](../operations/titration-r16-color-guide.md)、[水浴教学](../operations/fehlings-r2-color-guide.md)、
[滴定测试](../../tests/test_titration_r16.py)、[水浴测试](../../tests/test_fehlings_r2.py)。

<a id="mat-003"></a>
### MAT-003 — 几何要符合声明的容器与运动范围

基于已提供的管腔/轴向 profile、单位和局部坐标构造液体，不从玻璃外包围盒直接假定内腔。
需要体积控制时考虑锥形截面等非线性体积—高度关系。检查穿壁、重叠、共面闪烁、异常底面和错误液面。
动态沉淀应核对固定底部、增长方向、上层样液边界和重置后几何；这些是视觉参数，不自动等于真实产率。
采用刚性跟随的假液体必须说明可用倾角/动作范围，而不能暗示完整自由液面仿真。

依据：[假液体测试](../../tests/test_generate_visual_static_liquid_prototype.py)、
[水浴 r2 几何测试](../../tests/test_fehlings_r2.py)、[贴壁液体记录](../records/2026-09-07-titration-r13-fitted-visual-liquid.md)。

<a id="mat-004"></a>
### MAT-004 — 视觉修改与物理分离

当修改被声明为视觉修改时，不附带增加液体碰撞、刚体、质量或改变生产者物理配置。
保存前后物理比较与范围记录；依赖资产原样保留或按允许的明确覆盖路线处理。
动态视觉 Mesh 更新要同时保持有效的拓扑、点数据、extent/法线与绑定，渲染回放恢复实际记录的几何。

依据：[滴定单材质差异](../records/2026-09-07-titration-r16-single-material.md)、
[沉淀几何与回放](../records/2026-09-08-fehlings-water-bath-r2-sedimentation.md)、
[ASSET-004](asset-intake.md#asset-004)。

## 推荐做法

<a id="mat-005"></a>
### MAT-005 — 按物理含义分层，不按颜色阶段复制

同一液相的连续变色优先复用同一材质，按参数更新；阶段名称保留在任务状态中。
几何可按侧壁/表面等需要分部件，不要求任何液体都必须恰好一个 Mesh。
样液与固体沉淀是不同组成，可以分别使用材质；表面/体积光学、其他明确渲染需求也可记录例外。
避免为每个颜色阶段重复建同形状的完整液体，再通过可见性切换掩盖连续参数需求。

<a id="mat-006"></a>
### MAT-006 — 先用可解释参数，再验收视觉

将颜色、透明度、沉淀进度等由体积或有效时间驱动的计算放在可独立测试的逻辑中，
说明插值、保持区间、夹取边界和重置。正常帧间更新不应在声明为连续的区间发生意外跳变。
参数值由任务选择，滴定的淡粉区间和水浴的 30/60 秒不是跨任务默认值。

## 验证与限制

对实际目标运行时检查初始、中间、终点及重置的 Shader 和几何，再做截图检查。
水中或嵌套透明层可能遮挡颜色；附加正确标注的观察视角，记录限制，不能只凭数值正确宣布“看得清”。
需要修改已限定的资产/照明范围时形成明确变更及新验证，不隐瞒失败样例。

变更记录：2026-09-08 从已验证的滴定/水浴和早期原型提炼；不新增化学或流体能力声明。
