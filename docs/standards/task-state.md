# 交互与状态规范

状态：当前。适用于场景携带的任务控制/视觉状态逻辑；不在此仓库建立 episode runner 或 benchmark evaluator。

## 强制要求

<a id="state-001"></a>
### STATE-001 — 规则、配置和实际行为一致

明确操作条件、时间/体积等驱动变量、允许完成的条件及失败/恢复规则。
生成代码、内嵌控制器、任务说明、VR 配置和指标引用不得保留互相矛盾的旧语义。
显示达到终态不自动等于任务成功；若两者刻意分离，说明原因和等待条件，不能误导操作者。

依据：[滴定连续流量规则](../records/2026-09-07-titration-r15-continuous-flow.md)、
[水浴 30/60/3 秒规则](../records/2026-09-08-fehlings-water-bath-r2-sedimentation.md)、
[纯逻辑测试](../../tests/test_fehlings_r2.py)。

<a id="state-002"></a>
### STATE-002 — 声明并一致使用时间与单位

明确时间来自仿真步、累计有效交互还是现实墙钟；以仿真时间声明的计时不得因暂停或离线等待继续推进。
声明角度单位、流量/体积/高度单位及有效条件，处理区间边界、剩余量和暂停/恢复。
来自实际物理关节或物体姿态的交互不得以静态 USD pose 冒充 live 状态；读取不可用时按声明的规则暂停或报告无效。

依据：[滴定策略与测试](../../tests/test_titration_r15.py)、
[水浴运行验证](../../scripts/validate_fehlings_water_bath.py)。

<a id="state-003"></a>
### STATE-003 — 重置必须覆盖逻辑与呈现

列出重置项：计时/累积量、阶段、成功与失败标记、材质、可见性和动态几何等。
重置后外观不能仍显示上一轮反应结果。明确重置与当步更新的先后关系，并验证所有受影响状态。
若存在必须依赖运行时物理初始化的重置项，明确前置条件；不要因位姿不可读而悄悄遗漏本可独立恢复的视觉状态。

依据：[水浴无位姿重置测试](../../tests/test_fehlings_r2.py)、[滴定重置](../../tests/test_titration_r16.py)。

<a id="state-004"></a>
### STATE-004 — 分清瞬时显示、成功和证据

声明成功是实时重算还是锁定，以及何时清除。锁定成功后若仍允许操作，保存完成时需要的状态值，
不能用后续实时值重新解释完成时的结果。观察保持被打断、提前退出、过量等边界需按本任务规则验证。

依据：[滴定完成快照](../../scripts/titration_linear_policy.py)、[水浴成功锁定](../../scripts/fehlings_r2_state.py)。
两种任务的后续显示策略不同：滴定成功后仍会随继续出液变色；水浴成功后保留其完成状态。

## 推荐做法

<a id="state-005"></a>
### STATE-005 — 将纯计算与 USD 桥接分开

用独立可测试函数计算状态和外观，通过薄的目标运行时桥接层读取输入、更新关系指向的 Prim。
包内若嵌入脚本，应包含运行必需内容，不依赖制作者源码路径；记录版本与对应验证。
分层不表示把模拟器 SDK 导入纯包层，遵守 [ASSET-001](asset-intake.md#asset-001)。

<a id="state-006"></a>
### STATE-006 — 为新规则提供可读的观察入口

在任务根保存适当的阶段、进度及成功遥测，提供运行 Stage 的只读示例。
用状态名解释阶段，用连续变量表达连续外观；不因状态是离散枚举就把颜色改成突变。
新的语义在新版本说明中明确，旧包保留原版本。

## 物理测量补充

<a id="state-007"></a>
### STATE-007 — 测量结果必须绑定载荷和引擎条件

对受力、接触力等物理测量，使用已知载荷验证单位、方向、采样时间、休眠／稳定化条件、
滤波误差和恢复行为；传感器返回非零数值不等于测量正确。
区分瞬时值、滤波值、显示分度和实际误差，保留无效标记，不能用显示位数宣称测量精度。
关闭休眠等处理只在相应资产与 runtime 证据范围内采用，不推广为所有物体的默认设置。
对包含多个刚体 link 的测量设备，还要覆盖非测量 link 上的接触／载荷。
有限且稳定的读数仍可能遗漏载荷；更换测力通道后，重新验证原始量、实际 dt、滤波、去皮与卸载。

依据：[受力称重设备设计](../design/force-weighing-device.md)、
[称量 r1 记录](../records/2026-09-09-solid-weighing-force-r1.md)。
该案例的可搬动机身不继承固定基座 v2 的资格。
