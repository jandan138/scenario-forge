01

工具先证明容器真的中空，再让 ConvertAsset 负责 SDF / convexHull 与 PBD；Scenario Forge 只接收合格证据、复制依赖、组装交付。两个仓库各做自己擅长的部分。

03

两条命令，得到一个可交付 ZIP

使用 EOS 已管理的 Isaac Sim 4.1 Python。不要复制或修改源场景，也不要为本工具临时建新环境。

先检查

让工具告诉你 composed stage 中应该选哪个完整 prim。

export SCENARIO_FORGE_CONVERTASSET_ROOT=/path/to/ConvertAsset
export EEOS_ISAACSIM41_PYTHON=/path/to/eos-isaac41/bin/python

scenario-forge liquid inspect \
  --scene /path/to/scene.usd

再生成

一次只处理一个容器；液位是稳定后的 q95 高度比例。

scenario-forge liquid add \
  --scene /path/to/scene.usd \
  --container /World/obj_graduated_cylinder \
  --fill 0.40 \
  --out /path/to/delivery
给同事什么：scene__liquid__obj_graduated_cylinder__fill40.zip。解压后打开同名 .usd；必须保留旁边同名 _deps/。USD 不内嵌机器人，claim 只到合格初始液体。

05

拒绝不是坏结果，是避免做出假液体

失败时不会留下正式 USD/ZIP。所有中间文件和日志移入同名 _diagnostics/，按下面路线处理。

NO CAVITY只能看到实体 bbox回 ConvertAsset 修几何或补 source-bound hollow-body 语义；不要在 Scenario Forge 塞隐藏盒。
AMBIGUOUS多个空腔无法区分选择更精确的容器 prim；最大空腔不足其它候选 2× 时默认拒绝。
RUNTIME版本不是 4.1检查 EEOS_ISAACSIM41_PYTHON。工具会清除 4.5 wrapper 的临时环境注入。
LEAK / DRIFT漏液或容器移动阅读三轮 JSON；由 ConvertAsset 修 collider/资产物理，再重跑完整资格验证。
BUDGET超过 10,000 粒子首版固定 Task02 粒子尺度，不自动变粗。需要新配方时应版本化，而不是暗改。
FORMAL OUTPUT失败后看不到 ZIP这是预期行为。只有生产者通过且最终自包含场景再跑 8 秒通过才晋级。
