Task 02 · r8.7 · GPU-PBD vessel repair

让量筒真正装得住液体

不是把碰撞参数一味调大。正确做法是保留透明量筒的外观，再给它做一个 GPU 算得动、内部真正中空的隐形碰撞内胆。

01先找准病因

它看起来像杯子，物理上却不一定是杯子

视觉模型只负责“像不像量筒”；液体碰撞模型负责“能不能把粒子留在里面”。原资产是适合渲染的开边薄壳，直接交给 GPU 做凸分解时，内腔无法得到稳定表达。

VISIBLE MESH

眼睛看到的是对的

透明筒壁、刻度、底座都正常，尺寸也没有错。它不该因为物理问题被替换或改粗。

COLLISION MESH

GPU 摸到的是错的

薄面、开口边和不稳定的分解结果，会让粒子穿壁、从底部漏出，甚至触发 GPU cooking 错误。

LIVE READBACK

旧证据读错了状态

simulationPoints 是写入的初值；真正判断是否漏液必须读运行中的 points。

纠错证据：改用实时 points 后，旧量筒三次只留下 43–45 / 548 粒。问题不是“液体颜色太淡”，而是碰撞容器根本没有成立。
02重建隐形内胆

外观不动，只重做液体真正接触的那一层

我们没有拿圆柱体粗暴套住量筒，也没有修改原始视觉 mesh。ConvertAsset 参考已经跑通的 LabUtopia 0812 容器拓扑，把模板按量筒的实测半径和高度变形，生成一个source-derived、封闭、可三角化的隐藏碰撞网格。

为什么这不是“一个实心 GPU 凸包”？
入口只有一个隐藏 mesh prim，但 convexDecomposition 会把它烹饪为若干可由 GPU 处理的凸组成部分，从而共同表达杯壁和中空内腔。若直接把整个量筒做成单一 convex hull，杯口会被封住，液体反而进不去也倒不出。
03让初值和容器对齐

粒子参数不乱改，先让它们站在正确的位置

最终方案沿用 0812 已验证的轻量液体参数，只把外观调成更易观察的蓝色。真正解决“刚抬量筒就冒出一坨液体”的关键，是先让量筒在 755 mm 桌面上自然落稳，再把预沉降粒子保存到量筒的局部坐标中。

沿用的液体基线

不增加体积光、不增加额外灯光，也不靠高成本材质掩盖粒子。颜色只影响看见什么，不影响碰撞。

05再让机器人动

液体没漏之后，剩下的问题其实是机器人动作

早期快速抬升让量筒在闭合夹爪里滑了约 101.7 mm。液体本身没有先坏，是容器从机器人预期的抓取位姿中滑走了。最终修复没有再动碰撞或液体参数，而是把 100 mm 抬升拉长到 2 秒。

为什么等待 3 秒，而不是一直等？
实验每 0.25 秒统计一次粒子归属。候选停留时间为 3、4、5、6、8 秒；3 秒已经是三次冷启动全部通过的最早候选。另一条流动 canary 在 2 秒达到 556 / 580，继续等到 8 秒也没有改善，所以更长等待只会增加动作时间。
06照着复现

把这套方法迁移到下一个容器

不要复制量筒的固定尺寸；复制的是工作方法：先拓扑、再静态保液、再规定轨迹、再打包、最后跑机器人。

生产方必须交付

  • 视觉 mesh 保持不变，隐藏碰撞 mesh 可追溯到源资产或已验证模板。
  • 边界边和非流形边为 0，并记录 cavity 半径、底面和杯口。
  • Isaac Sim 4.1 使用实时 points 完成三次冷启动。
  • 容器静态保液、GPU cooking、最低帧率和规定轨迹倒液均通过。
  • package、profile、report、particle state 和 SHA-256 互相绑定。

关键参数清单
convexDecomposition；碰撞 contact offset 5 mm；碰撞 rest offset 3 mm；minimum thickness 1 mm；voxel resolution 500000；液体 580 粒；粒子宽度 5.94 mm；粒子 contact offset 5 mm；粒子 rest offset 0。它们是本资产的验证结果，不是所有容器的通用常数。

五件不要做的事

  • 不要先靠增大 rest offset 救一个开边薄壳。
  • 不要把单一实心 convex hull 当作中空容器。
  • 不要读取 simulationPoints 冒充实时保液结果。
  • 不要分别修正容器高度和粒子高度。
  • 不要在 Scenario Forge 或 GenManip 写量筒专用物理补丁。

我们已经证明：这个精确 r8.7 任务包能在 Isaac Sim 4.1 中完成 3 / 3 脚本机器人接触倒液（scripted oracle）。
我们还没有证明：学习策略成功、正式 eBench benchmark 成功、液体 metric 已激活，或仿真参数与真实液体完成标定。
