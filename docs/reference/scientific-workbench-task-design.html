Scientific Workbench Task Design

本页由固定飞书快照生成，不是第二份手工任务定义。

Source warnings

  • Task Design 正文声明第一期 17 tasks，但嵌入表格实际包含 18 行任务；目录按表格 18 行保存。
  • Task Design 注意事项称仿真液体任务暂定只评估动作、忽略液体，但多项 Progress Score 仍包含液体转移比例；两种原文均保留。
  • Task Design 正文称长程实验操作为 7-11 steps，但第 18 行旋转蒸发记录为 13 steps；未修改源值。

1. 液体倾倒：锥形瓶→量筒

2

规范化角色

过程概述

辅助臂抓量筒并保持目标位置（抓） → 操作臂拿起锥形瓶（拿起） → 双臂协同调整瓶口与量筒口对准（对准） → 操作臂倾斜完成倾倒（倾倒） → 操作臂放回锥形瓶（放置）

Progress Score · 合计 1.00

  • 时序 1 · 0.20：锥形瓶离开桌面
  • 时序 2 · 0.30：操作臂仍夹持锥形瓶，锥形瓶瓶口位于量筒口上方，且瓶口中心xy平面投影位于量筒口区域内
  • 时序 3 · 0.20：最终帧：量筒内包含锥形瓶初始液体的比例超过50%
  • 时序 3 · 0.20：最终帧：量筒内包含锥形瓶初始液体的比例达到本任务配置的全部转移阈值
  • 时序 3 · 0.10：最终帧：锥形瓶正立位于本任务配置的归还区域内，由承托面支撑且机械手已释放
