## 1. 液体倾倒：锥形瓶→量筒

- Stable ID：`scientific_workbench_pour_flask_to_cylinder`
- 飞书行号：`2`
- 模式：联合 → `joint`
- 步骤数：5
- 原子技能：抓、拿起、放置、倾倒、对准 → `grasp`, `pick`, `place`, `pour`, `align`
- 核心资产原文：锥形瓶、量筒
- 规范化资产角色：`erlenmeyer_flask`, `graduated_cylinder`
- 长程/精细：`middle` / `high`

过程概述：

辅助臂抓量筒并保持目标位置（抓） → 操作臂拿起锥形瓶（拿起） → 双臂协同调整瓶口与量筒口对准（对准） → 操作臂倾斜完成倾倒（倾倒） → 操作臂放回锥形瓶（放置）

Progress Score（原始权重合计 `1.00`）：

- 时序 1 · 0.20：锥形瓶离开桌面
- 时序 2 · 0.30：操作臂仍夹持锥形瓶，锥形瓶瓶口位于量筒口上方，且瓶口中心xy平面投影位于量筒口区域内
- 时序 3 · 0.20：最终帧：量筒内包含锥形瓶初始液体的比例超过50%
- 时序 3 · 0.20：最终帧：量筒内包含锥形瓶初始液体的比例达到本任务配置的全部转移阈值
- 时序 3 · 0.10：最终帧：锥形瓶正立位于本任务配置的归还区域内，由承托面支撑且机械手已释放
