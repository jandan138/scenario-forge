# Task10 显色原理：自包含 HTML 教程

用户要求把粒子分组与变色逻辑整理成详细、系统、通俗易懂的自包含 HTML。
新增文档模板与内嵌图片生成脚本，不修改场景、粒子参数、控制器、VR 配置或既有交付包。

## 内容和来源

依据 `task10_pbd_policy.py`、`task10_pbd_runtime.py` 和当前 VR 包的独立材质路径。
解释 Source / DeadPrecharge / Falling / Receiver 的分工、源到滴嘴的受控守恒转移、
穿口及主体液体接触、粒子合并保留位置/速度、按有效接收量显色以及独立 Shader 参数。
明确颜色曲线不是 pH 求解；ON 是静态字样，磁子动画不产生物理搅拌。

交互包括接收/漏接分步示意、颜色滑块、关阀保持、成功锁定、过量历史、图片切换和自查题。
示意图不冒充 PBD 仿真，颜色色块不冒充 OmniGlass 渲染。页面保存三张实际状态回放截图，
过量截图明确属于重置后的另一轮，避免与成功锁定语义相矛盾。
